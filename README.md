# 柒柒游电竞酒店官网模板

已搭建 5 个页面：首页、关于我们、店铺展示、合作联营、联系我们。品牌主体为四川柒柒游酒店管理有限公司。

## 打开预览

当前预览地址：http://localhost:4173/

预览服务关闭后，在此目录运行 `npm run dev`，或双击 `启动官网预览.cmd`。浏览器访问上述地址即可。需要安装 Node.js；本机已具备。无需安装项目依赖。

请通过预览服务访问，不要直接双击 index.html，以保证图片和内页路径正常。

## 怎样自由修改

主要内容在 `site.config.js` 中。用文本编辑器打开，保留引号和逗号，修改文字后保存，再刷新浏览器。

| 想修改的内容 | 配置位置 |
| --- | --- |
| 公司全称、品牌、英文名 | company、brand、brandEnglish |
| 主品牌色 | accent，例如 #ff480d |
| 首页标题、副标题、说明和首图 | hero |
| 公司介绍和品牌主张 | introduction、positioning、brandStatement、brandDescription |
| 八项服务的标题与内容 | services |
| 空间分类、图片、介绍、标签 | gallery |
| 合作首屏标题、介绍、双方职责、合作步骤 | cooperation |
| 电话、联系人、邮箱、办公地址 | contact |
| 企业微信、公众号二维码、地图链接 | contact.wechatImage、officialAccountImage、mapUrl |
| 备案号 | contact.icp |

将替换图片放到 `assets` 目录，配置中填写 `/assets/你的图片.jpg`。建议空间图使用横向 16:9 图片，至少 1600 像素宽。画廊主图与细节图使用同一图片的不同裁切；前两个空间类别必须保留，供首页及其他内页调用。首页首图可单独配置。

手机号填写后，导航、联系页和页脚自动显示可拨打号码。二维码和备案号为空时不显示，不会使用参考站资料。尚未提供电话及地址时，页面显示“即将公布”。

如需改变页面整体结构、各区块顺序与其他文字，编辑 `src/app.js`；间距、字号、背景和响应式样式在 `src/styles.css`。修改公司名称时，也请同步修改 `index.html` 的初始标题与描述。

## 现有交互

- 五个页面可直接访问，支持刷新及浏览器前进后退。
- 电脑端固定导航与当前页面高亮，手机端折叠菜单。
- 首页手动切图、品牌故事切图。
- 空间分类切换、图片放大、Esc 关闭、键盘切换分类。
- 合作页锚点定位到合作模式与八大服务。
- 联系信息补齐后显示电话、邮箱、二维码及地图链接。

目前是展示型官网模板，不包含后台 CMS、订房系统、表单收件或在线支付。

## 生成静态发布文件

运行 `npm run build`，将得到 `dist` 目录。该目录包含完整的静态页面与本地素材，可以交给网站运维部署到支持静态网站的服务器。不需要数据库，也不需要持续运行 Node 服务。

页面地址：`/`、`/about/`、`/shop/`、`/teamwork/`、`/contact/`。服务器需支持目录默认文档 `index.html`。不建议部署在域名子目录，除非同步调整资源路径。

本次已提供完整源码和本地预览，尚未发布到公网或绑定公司域名。
