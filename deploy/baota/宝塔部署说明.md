# 柒柒游官网 · 宝塔部署说明

本包适用于宝塔面板的静态网站，以下步骤按 Nginx 环境编写。服务器只需要 Web 服务，不需要 Node.js、PHP 程序、数据库、反向代理或进程守护。

## 1. 新建网站

在宝塔面板进入“网站 → PHP 项目 → 添加站点”（不同版本菜单名称可能略有区别）。填写自己的域名，PHP 版本选择“纯静态”，数据库和 FTP 按需选择，本项目不需要数据库。

默认站点目录通常类似 `/www/wwwroot/你的域名`。将域名解析到服务器，再使用该域名访问。

## 2. 上传并解压

上传 **柒柒游官网-宝塔部署包.zip** 到该站点目录，在宝塔文件管理中解压。首次部署到新网站时，用本包的 `index.html` 和 `404.html` 覆盖面板自动生成的同名默认页面；已有业务网站请先备份。

这个 ZIP 内没有外层项目文件夹，解压后的结构应直接是：

```text
/www/wwwroot/你的域名/
├── index.html
├── 404.html
├── site.config.js
├── assets/
│   ├── favicon.svg
│   ├── room-twin.jpg
│   └── room-party.jpg
├── src/
│   ├── app.js
│   └── styles.css
├── about/index.html
├── shop/index.html
├── teamwork/index.html
└── contact/index.html
```

网站设置中的“网站目录 / 运行目录”应指向含 `index.html` 的这一层。不要让压缩工具再套一层 ZIP 同名文件夹，也不要将域名指向父目录。网站资源使用根路径，请部署在独立域名或子域名根目录，而非 `/hotel/` 等子路径。

## 3. 默认文档与页面路由

在网站设置的“默认文档”中将 `index.html` 放在首位。五个页面都有实际的 HTML 文件，通常使用宝塔新建静态站点的默认配置即可访问，无需特殊伪静态规则。

如需显式配置 Nginx，在该网站“伪静态”中填写下面的片段，或使用随附的 `nginx-location.conf`：

```nginx
location / {
    index index.html;
    try_files $uri $uri/ =404;
}
```

如果网站现有配置已经有 `location /`，请修改现有区块，不要重复添加。此文件只是站点配置片段，不是完整 `nginx.conf`，不要替换宝塔全局配置或现有 SSL 配置。原来用于其他框架的首页兜底、PHP 转发规则不应继续作用于本静态站点。

在该网站“配置文件”的 `server { ... }` 内，检查已有 404 配置；将同类规则调整为以下一条，已有相同配置则保留：

```nginx
error_page 404 /404.html;
```

保存时通过宝塔的 Nginx 配置校验后重载。未知页面应返回 HTTP 404，并显示本站错误页面。

如果服务器使用 Apache：本包仍是标准静态文件，设置默认首页 `index.html` 即可；不要粘贴上述 Nginx 片段。自定义错误页可在允许覆盖配置时使用 `ErrorDocument 404 /404.html`。

## 4. 访问核对

依次打开域名首页以及 `/about/`、`/shop/`、`/teamwork/`、`/contact/`，刷新内页并查看图片是否显示。`/shop` 等不带尾斜杠的地址也应能访问或跳转到对应目录。

再访问一个不存在的路径，例如 `/missing-page/`，应显示 404。网站正常访问后，可在宝塔的 SSL 设置中为实际域名配置证书。

## 5. 常见问题

| 现象 | 检查位置 |
| --- | --- |
| 仍显示宝塔默认页 | 核对运行目录，并确认项目 index.html 已覆盖默认页面；刷新浏览器 |
| 首页 403 | 确认运行目录内存在 index.html，文件和目录允许 Web 服务读取 |
| 内页 404 | 检查 about、shop、teamwork、contact 文件夹是否一起上传，且内有 index.html |
| 图片或样式 404 | 确认 assets、src 和 site.config.js 与首页同层，网站在域名根目录运行 |
| 修改后还是旧内容 | 强制刷新浏览器；如已启用 CDN 或面板静态缓存，同步清理相应缓存 |
| 保存配置提示 duplicate location | 现有站点已有 location /，合并到现有区块，不要再添加同名区块 |

## 6. 后续修改

可以直接在宝塔文件管理中编辑 `site.config.js` 来更新标题、业务介绍、电话与地址。替换图片时保持原文件名，或同步更新配置中的图片路径。版式修改在 `src/styles.css`，页面结构和其他文字在 `src/app.js`。

也可以在本机源码项目中执行 `npm run build` 后，用最新 `dist` 内容更新站点。只需上传网页构建产物，源码仓库里的 `package.json`、`vercel.json`、开发脚本、研究资料和测试截图不属于运行文件。

本次交付是可上传部署文件，未连接或修改你的宝塔服务器。实际域名、站点配置与上线状态以服务器部署结果为准。

参考：[宝塔添加站点官方说明](https://docs.bt.cn/user-guide/site/php/create-web)、[Nginx 静态文件与目录首页](https://docs.nginx.com/nginx/admin-guide/web-server/serving-static-content/)。
